# 작업표시줄 고양이 콘셉트 제안 v0.1

상태: 전체 게임 방향은 유지, 현재 작업표시줄 행동 원화는 재설계 중  
작성일: 2026-07-10  
목적: 구현에 들어가기 전에 작업표시줄 고양이의 모습, 유휴 행동, 입력 반응, 확장 게임 연결 방식을 비교하고 권장안을 정한다.

사용자는 `한 마리의 오늘 가게` 기본 방향과 권장 기본값으로 작업표시줄 프로토타입을 만드는 것을 승인했다. 다만 현재 v2 도구 요리사 아트와 v3 냄비 두드리기 실험은 사용자 시각·콘셉트 검수에서 탈락했다. 세부 행동 원화는 `docs/recovery-audit.md`의 게이트에 따라 다시 결정한다.

## 2. 세 가지 방향

### A. 한 마리의 오늘 가게 — 권장 기본안

- 투명 오버레이의 목표 범위는 약 168~200 × 104~120px이다. 현재 프로토타입의 238 × 156px보다 작게 시작하고 DPI에 따라 스케일한다.
- 대표 고양이 한 마리와 현재 업무를 보여 주는 소품 한 개만 상시 노출한다.
- 확장창에서 정한 직업이 작업표시줄 행동이 된다.
  - 요리: 썰기, 젓기, 반죽, 오븐 확인
  - 농장: 물주기, 씨앗 정리, 수확물 포장
  - 식당: 주문 확인, 접시 닦기, 서빙
  - 의상: 재봉, 리본 정리, 거울 보기
  - 파견: 가방 싸기, 지도 보기, 상자 포장
- 특별한 상황에만 친구나 손님 고양이 한 마리가 잠깐 방문한다.

장점: 작은 크기에서 표정과 행동이 가장 잘 읽히고, 제작량과 화면 점유를 통제하면서 모든 확장 시스템을 표현할 수 있다.

### B. 두 고양이 주방 듀엣

- 약 232 × 100px에 주인공과 조수 또는 손님을 배치한다.
- 키보드는 주인공, 마우스는 조수가 반응하며 재료 전달·맛보기·하이파이브 같은 합동 행동을 만든다.
- 친밀도와 관계 조합에 따라 새로운 합동 행동을 해금한다.

장점: 관계성과 캐릭터성이 강하다.  
위험: 고양이·의상·직업 조합만큼 애니메이션 제작량이 급증한다. A안의 성장 해금이나 특별 이벤트로 넣는 것이 적합하다.

### C. 생산 릴레이

- 최대 약 300 × 90px 또는 작은 슬롯 세 개를 사용한다.
- 농장 고양이가 재료를 전달하고, 요리 고양이가 조리하고, 서빙 고양이가 포장하는 실제 생산 큐를 보여 준다.

장점: 확장 게임의 경제 흐름을 가장 잘 보여 준다.  
위험: 화면 점유와 정보 밀도가 높고 다중 모니터·DPI·클릭 통과 처리가 어렵다. 출시 후 확장 모드나 이벤트에 적합하다.

## 3. 권장 최종 조합

기본은 A안으로 시작하고, 성장과 관계 콘텐츠에서 B안의 방문 고양이를 간헐적으로 추가한다.

핵심 문장:

> 확장창에서 오늘 맡긴 일을, 작업표시줄 위 고양이가 사용자의 활동과 함께 수행한다.

이 구조는 세 프로젝트 세계를 자연스럽게 연결한다.

- 당신에게 고양이: 고양이 성격, 관계, 표정과 교감
- 두근두근 레스토랑: 요리, 주문, 서빙과 매장 성장
- 에브리타운: 농사, 생산, 재료 이동과 마을 확장

## 4. 기본 모습

- 배경 패널을 항상 표시하지 않고 투명 무대와 얇은 받침 그림자만 둔다.
- 고양이 한 마리의 실루엣과 얼굴이 먼저 읽히고, 소품은 한 번에 하나만 둔다.
- 옷, 모자, 도구, 현재 생산품이 확장창의 실제 선택과 동일해야 한다.
- 상시 숫자 타이머와 자원 HUD는 제거한다. 호버하거나 완료됐을 때만 최소 정보가 나타난다.
- 완료는 팝업 대신 고양이가 완성품을 들고 작은 체크 표시를 보여 준다.
- 투명 영역은 클릭을 통과시키고 고양이와 명시적 소품만 입력 영역으로 사용한다.
- 기본 효과음은 끄며, 표정·포즈·작은 파티클로 반응을 전달한다.

현재 v31 요리 스프라이트는 첫 Cook_Stir 참고 동작으로 재활용할 수 있다. 다만 몸·얼굴·팔·옷·도구가 한 이미지에 합쳐져 있어 최종 Unity 자산은 레이어 분리 또는 Unity 2D Animation 리그가 필요하다.

## 5. 유휴 행동 상태

| 입력이 없는 시간 | 고양이 행동 | 의도 |
|---|---|---|
| 0~20초 | 현재 업무를 자연스럽게 계속하고 눈·귀·꼬리만 가볍게 움직임 | 사용 흐름을 끊지 않음 |
| 20~90초 | 작업 속도를 낮추고 도구 정리, 주변 보기, 그루밍, 차 마시기 중 하나 수행 | 살아 있는 느낌과 반복 완화 |
| 90초~5분 | 기지개, 간식, 창밖 보기, 짧은 졸기 | 자리를 비운 상태를 자연스럽게 표현 |
| 5~10분 이상 | 낮은 프레임의 휴식 또는 수면 모드 | 방해와 전력 사용 감소 |
| 사용자 복귀 | 놀라서 깨기 또는 하품, 인사, 업무 복귀 | 복귀를 알아챘다는 정서적 보상 |

규칙:

- 방치해도 생산 손해나 호감도 하락이 없다.
- 같은 마이크로 유휴 행동을 연속 선택하지 않는다.
- 각 행동에 가중치와 재사용 대기시간을 둔다.
- 완료나 희귀 방문을 제외하면 큰 말풍선과 즉시 처리 알림을 띄우지 않는다.

## 6. 키보드·마우스 반응

입력은 고양이의 표현을 풍부하게 하지만 핵심 경제 보상을 직접 만들지 않는다.

| 사용자 행동 | 작업표시줄 반응 | 직업별 예시 |
|---|---|---|
| 느린 키 입력 | 좌우 앞발을 번갈아 한 번씩 움직임 | 썰기, 반죽 누르기, 씨앗 심기, 주문 도장 |
| 빠른 타이핑 | 현재 업무 애니메이션을 상한까지 부드럽게 가속 | 러시아워 조리, 빠른 포장, 재봉틀 가속 |
| 커서가 가까워짐 | 눈, 귀, 고개가 좌·중·우로 추적 | 도구를 든 채 사용자를 바라봄 |
| 빠른 포인터 이동 | 한두 걸음만 쫓거나 꼬리가 반응한 뒤 제자리 복귀 | 실타래나 작은 재료를 쫓음 |
| 일반 클릭 활동 | 짧은 작업 펄스 | 벨 누르기, 도마 치기, 접시 놓기 |
| 스크롤 활동 | 회전 또는 밀기 동작 | 국자 젓기, 밀대 굴리기, 실타래 굴리기 |
| 고양이 직접 호버 | 머리를 들이밀거나 기대함 | 쓰다듬어 달라는 신호 |
| 고양이 직접 클릭·드래그 | 쓰다듬기, 들리기, 위치 이동 | 짧은 감정 반응 후 업무 복귀 |

입력 이벤트를 100~250ms 단위의 활동 펄스로 합쳐 애니메이션이 매 키마다 끊기지 않게 한다. 실제 키 값, 문자열, 창 제목, 실행 앱, 클릭 대상, 클립보드나 화면은 읽거나 저장하지 않는다.

전체 데스크톱 반응은 최초 실행 때 다음 중 선택한다.

1. 입력 반응 끄기
2. 게임 창 안에서만 반응
3. 전체 데스크톱 활동량에 반응

전체 활동 모드에서도 도메인에는 KeyboardPulse, PointerMoveIntensity, PointerClickPulse, ScrollPulse 같은 익명 신호만 전달한다. 로그, 세이브, 텔레메트리에는 원시 입력을 남기지 않는다.

## 7. 보상과 확장창 연결

권장 루프:

1. 확장창에서 고양이, 옷, 도구, 직업과 작업을 선택한다.
2. 작업표시줄 고양이가 그 모습과 행동으로 바뀐다.
3. 작업은 시작 시각과 종료 시각을 기준으로 자동 진행된다.
4. 입력 반응은 애니메이션과 교감 표현만 풍부하게 한다.
5. 완료 시 고양이가 결과물을 조용히 보여 준다.
6. 고양이나 결과물을 클릭하면 확장창의 정확한 생산 화면으로 이동한다.
7. 확장창에서 얻은 새 옷·도구·관계·설비가 다시 작업표시줄 모습과 행동을 늘린다.

확장 UI는 여러 독립 창을 동시에 띄우지 않는다. 작업표시줄 위에 단일 도킹 패널 하나를 열고 농장·요리·의상·관계를 탭과 단계 이동으로 전환해 화면 가림과 뒤쪽 클릭 누수를 줄인다.

경제 안전장치:

- 키나 클릭 한 번마다 코인·재료를 지급하지 않는다.
- 생산은 작업 ID, 시작 시각, 종료 시각, 수령 여부로 계산하고 한 번만 수령한다.
- 입력 반응을 꺼도 진행에서 불이익이 없다.
- 활동 보너스를 넣더라도 친밀도 같은 비경제 보너스에 낮은 일일 상한을 둔다.
- 프리미엄 재화와 핵심 생산 속도를 입력 횟수에 연결하지 않는다.

## 8. 방해 최소화 기능

출시 품질에서 다음은 부가 기능이 아니라 필수다.

- 작업표시줄 위 고정, 일반 항상 위, 다른 앱 뒤, 완전 숨김 모드
- 투명 영역 클릭 통과와 직접 상호작용 영역 분리
- 우클릭 또는 단축키로 즉시 반투명·클릭 통과
- 위치 잠금, 스냅, 좌우 반전, 모니터 선택, 75/100/125/150% 크기
- 작업표시줄 자동 숨김과 모니터별 DPI 대응
- 위치·크기·투명도 원클릭 복구와 단축키
- 전체화면 게임·프레젠테이션 감지 시 자동 숨김 또는 뒤로 보내기
- 전체·감소·정지의 모션 단계와 파티클·팝업 개별 끄기
- 15/30/60FPS와 필요할 때만 그리는 저전력 모드
- 절대로 다른 앱의 포커스를 빼앗지 않기

## 9. Unity 이관 구조

애니메이션은 세 층으로 분리한다.

1. 기본 행동: Enter, Work, MicroIdle, Break, Sleep, Celebrate, Hidden
2. 입력 반응: TapLeft, TapRight, Look, ClickReact, Pet
3. 상태 표시: Ready, NeedAttention, Visitor

우선순위:

전체화면 숨김 > 완료 축하 > 직접 상호작용 > 입력 반응 > 상태 표시 > 업무 > 유휴

권장 책임 분리:

- CatAmbientDirector: 업무와 유휴 상태 선택
- ReactionAccumulator: 익명 입력 펄스 합산, 강도 상한과 쿨다운
- TaskbarCatPresenter: 도메인 상태를 Animator와 레이어 자산에 반영
- WorkOrderService: 시간 기반 생산과 중복 수령 방지
- IActivitySignalSource: 웹 입력과 Windows 전역 입력 어댑터 분리
- IOverlayHost: 위치, 클릭 통과, DPI, 전체화면, 모니터 처리
- IClock, ISaveRepository: 시간과 저장 구현 교체
- CatBehaviorProfile, TaskbarActivity, ReactionTuning: ScriptableObject 데이터

세이브에는 고양이·옷·업무·작업 시각·기분·완료 보상만 저장하고 현재 애니메이션 프레임이나 입력 이벤트는 저장하지 않는다.

## 10. 첫 프로토타입 범위와 판정 기준

첫 검증은 A안의 주방 고양이 한 마리로 제한한다.

- 업무: 젓기 1종
- 마이크로 유휴: 주변 보기, 그루밍, 도구 정리
- 장기 유휴: 기지개, 졸기
- 입력 반응: 좌우 키 펄스, 타이핑 속도 변화, 커서 추적, 직접 쓰다듬기
- 상태: 작업 중, 완료, 숨김
- 확장 연결: 현재 요리와 옷 한 벌이 즉시 반영

품질 판정 기준:

- 입력 반응이 즉시 읽히되 업무 애니메이션이 매번 처음부터 끊기지 않는다.
- 투명 영역이 일반 작업 클릭을 가로막지 않는다.
- 입력 반응을 꺼도 생산 결과가 동일하다.
- 30분 관찰에서 같은 마이크로 유휴 행동이 연속 반복되지 않는다.
- 완료를 놓쳐도 보상이 사라지지 않고 긴급 팝업이 없다.
- 저장·로그에 키 값, 문자열, 창 제목, 앱 이름, 클릭 대상이 없다.
- 확장창의 직업·옷·도구 선택과 작업표시줄 표현이 불일치하지 않는다.
- 100%, 125%, 150% DPI와 다중 모니터에서 위치·크기·클릭 영역을 확인한다.

## 11. 프로토타입에 적용한 기본 결정

1. 기본 직업은 요리 계열로 시작한다. 구체 행동은 미확정이며, 스튜+손도구와 냄비 두드리기는 재사용하지 않는다.
2. 상시 표시 고양이는 한 마리이며 친구 고양이는 이후 관계 이벤트로 남긴다.
3. 보통형 184 × 112px 투명 무대를 사용한다.
4. 웹 프로토타입은 페이지 내부 익명 입력만 반응한다. Windows 전역 입력은 최종 구현에서 명시적 동의 뒤 켜는 별도 어댑터로 남긴다.
5. 효과음은 사용하지 않고 몸짓과 작은 시각 효과만 사용한다.
6. 이미지 분류와 Unity 메타데이터 정리는 허용하지만 포팅 편의를 위해 이미지 품질을 낮추지 않는다.

## 12. 현재 결론

권장 방향은 한 마리의 오늘 가게다. 현재 구현 후보는 요리사 복장과 고양이의 꾹꾹이를 연결한 `한 덩어리 반죽 치대기`다. 1254px 중립 마스터에서 선언된 좌/우 앞발·접촉 반죽과 눈 마스크만 합성한 4상태 아틀라스가 런타임에 연결됐으며, 도구·전신 루프·입력 경제 보상은 사용하지 않는다. 내부/독립 시각 QA와 자동 검증은 통과했지만 사용자의 실제 로컬 연속 재생 승인이 남아 있으므로 상태는 `Implemented, not verified`다. 입력은 표현을 담당하고, 시간과 관리 선택이 경제를 담당한다.
