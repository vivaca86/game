# Harness Rules v1

## 목적
이 문서는 게임 개발 시 Chat 협의와 Codex 구현 작업이 충돌하지 않도록 하기 위한 공통 운영 규칙을 정의한다.

## 필수 규칙 (Mandatory)
1. 하지 말라고 한 작업은 절대 수행하지 않는다.
2. 업데이트/기획 변경으로 인해 더 이상 사용하지 않는 코드는 반드시 삭제한다.
3. 특정 파일/모듈 한 곳에 로직을 과도하게 집중시키지 않는다.
4. 필요 시 파일을 역할별로 분리하고, 메인 진입점에서 조합(연결)한다.
5. 모든 변경은 검증 절차(빌드/테스트/수동 체크)를 반드시 수행한다.

## 예외 처리
- 규칙 위반이 필요해 보이는 경우, 먼저 이유와 대안 2개를 제시하고 승인 후 진행한다.

## Codex 작업 출력 형식
모든 작업 결과는 아래 항목을 포함한다.

- 변경 파일 목록
- 삭제한 미사용 코드 목록(있는 경우)
- 검증 명령과 결과
- 남은 리스크 및 추가 TODO

## 적용 범위
- 본 규칙은 레포지토리 전체 작업에 기본 적용한다.
- 향후 하위 디렉토리에 별도 운영 규칙이 생기면, 더 구체적인 규칙을 우선 적용한다.
