# 개발 기반 체크리스트

최종 기준은 밝은 파스텔풍, 귀여운 마스코트형 몬스터, 한글 전용 UI, 데이터 분리형 카드 던전 게임이다.

## 개발 환경

- 로컬 실행: `node tools/serve-static.mjs`
- 정적 빌드: `node tools/build-static.mjs`
- 카드 데이터 재생성: `node tools/generate-full-card-data.mjs`
- 카드 이후 콘텐츠 재생성: `node tools/generate-full-content-data.mjs`
- 데이터 검증: `node tools/validate-data.mjs`
- 런타임 스모크: `node tools/runtime-smoke-test.mjs`
- `npm`이 설치된 환경에서는 `npm run dev`, `npm run build`, `npm run data:validate`도 사용할 수 있다.
- 현재 구조는 별도 번들러 없이 브라우저에서 바로 실행되는 정적 HTML 기준이다.

## 첫 작업 순서

1. 개발 환경 고정
2. 한글 데이터 구조 고정
3. 카드, 보석, 몬스터, 스테이지의 최소 샘플 데이터 투입
4. 데이터 검증 도구로 누락과 참조 오류 확인
5. 전투 코어가 새 데이터 구조를 읽도록 연결
6. 보상, 보석, 유물, 스테이지 진행을 순서대로 연결

## 데이터 원칙

- 게임에 보이는 모든 문구는 한글 데이터에서 관리한다.
- 카드명, 몬스터명, 스테이지명, 보상명, 버튼명, 도움말은 코드에 직접 박지 않는다.
- 시스템은 원형 장르의 흐름을 참고하되, 이름, 세계관, 몬스터, 카드 모양, 카드 일러스트, UI 톤은 독자 IP로 유지한다.
- 데이터는 먼저 작은 샘플로 검증하고, 같은 구조로 전체 규모까지 확장한다.

## 목표 콘텐츠 규모

- 카드: 113장
- 보석: 50종 이상
- 캐릭터: 20명 이상
- 스테이지: 15개 이상
- 유물: 16종 이상
- 기운: 12종 이상
- 이벤트: 10종 이상
- 업적: 160개 이상

## 진행 현황

- 카드 113장 풀 데이터 골격 완료
- 보석 58종 풀 데이터 골격 완료
- 캐릭터 23명 풀 데이터 골격 완료
- 스테이지 15개 풀 데이터 골격 완료
- 유물 16종 풀 데이터 골격 완료
- 기운 12종 풀 데이터 골격 완료
- 이벤트 10종 풀 데이터 골격 완료
- 업적 161개 풀 데이터 골격 완료
- 지원 몬스터 60종 데이터 골격 완료
- 카드명, 효과 설명, 태그, 일러스트 방향은 한글 기준
- 모든 목표 수량은 검증 도구에서 정확히 일치해야 통과한다.
- 효과, 해금, 보상, 참조 관계는 검증 도구에서 누락과 잘못된 참조를 검사한다.

## 런타임 연결 현황

- 데이터 로더와 ID 인덱스 연결 완료
- 캐릭터/스테이지 선택 후 데이터 기반 탐험 시작 가능
- 손패, 덱, 버림더미, 기운, 비용, 카드 사용 연결 완료
- 카드 효과 op의 기본 처리기 연결 완료
- 일반전, 정예, 이벤트, 보상, 보스 방 진행 연결 완료
- 카드, 보석, 유물, 별사탕 보상 선택과 다시 보기 연결 완료
- 업적 트리거와 보상 연결의 첫 런타임 경로 완료
- 보석 보관함, 보석 인스턴스, 카드별 소켓 장착 구조 완료
- 보석 효과가 카드 비용, 피해, 보호막, 표식, 메아리, 확산, 연쇄 유지에 반영된다.
- 런 상태 저장 스냅샷에 덱, 손패, 버림더미, 보석 보관함, 장착 소켓, 해금, 유물, 업적, 스테이지 진행이 포함된다.
- 유물 16종은 전투 시작, 전투 종료, 보상 개수, 별사탕, 상점/이벤트 비용, 연쇄 보조에 연결된다.
- 기운 12종은 시작 기운 지급, 카드 사용 후 조건부 피해/회복/별사탕/드로우/비용 감소, 보석 보상 확률에 연결된다.
- 현재 빌드 UI에서 보유 유물과 기운을 확인하고 저장/불러오기 후 복원한다.
- 장기 진행 프로필에 스테이지 클리어, 업적, 카드/보석/유물/기운/캐릭터 해금, 마을 보상을 저장한다.
- 새 탐험은 프로필의 캐릭터/스테이지 해금 상태와 보상 풀을 기준으로 시작한다.
- 클리어/실패 결과 화면에서 이번 탐험 통계와 신규 해금 내역을 확인한다.
- 적은 스테이지 순서와 방 종류에 따라 체력, 방어, 의도 수치가 보정되고 역할명이 붙는다.
- 특수 의도는 표식, 약화, 기운 감소, 방해 카드, 관통 피해, 전체 방어, 회복, 연쇄 감소, 호출을 처리한다.
- 보스는 체력 페이즈 규칙으로 친구 호출과 장벽 보정을 발동하며 결과 화면에 보스 변화 횟수를 기록한다.
- `src/core/balance.js`에서 보상 골드, 상점 비용, 스테이지 클리어 골드, 적 성장 보정값을 1차 관리한다.
- 캐릭터 패시브와 마을 성장 효과가 전투 시작, 카드 사용, 피격, 정예 보상, 보석 보상 확률에 반영된다.
- 밸런스 자동 점검은 `node tools/balance-simulation.mjs --runs=12 --stages=1,3,6,10,15`로 실행한다.
