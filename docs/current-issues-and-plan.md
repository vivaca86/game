## 확정된 결정

- 서비스 벨과 냄비 두드리기는 더 이상 제안하거나 재사용하지 않는다.
- 캐릭터 스타일은 Image 1 / `assets/concept/chef-cat-v9.png`에 맞춘다. Image 2의 반실사 3D풍은 새 원화의 스타일 기준으로 사용하지 않는다.
- 반죽은 좌우 두 개가 아니라 두 앞발 아래에서 가운데가 끊기지 않은 한 덩어리다.
- 생성된 좌/우/깜빡임 전체 그림을 그대로 프레임으로 쓰지 않는다. 한 반죽 중립 마스터에서 선언된 국소 마스크만 합성한다.
- 도구·액체·전신 6포즈 생성·전신 무한 루프·CSS 본체 흔들기를 사용하지 않는다.
- 현재 작업표시줄 반죽에는 완료·수령·보상 상태나 상시 단계 티켓을 만들지 않는다. 내부 시간 루프와 무관하게 고양이는 계속 움직인다.
- 드래그는 고양이 전체 위젯 이동이며 완료 수령 클릭과 구분한다.
- 확장 메뉴가 열려도 고양이는 사라지거나 비활성화되지 않는다. 고양이는 열기/닫기의 동일한 토글 컨트롤이며 메뉴 위에서도 드래그할 수 있다.
- 메뉴가 열린 상태의 고양이 클릭은 항상 닫기를 먼저 수행하며, 뒤에서 작업이 완료됐더라도 그 클릭으로 보상을 수령하지 않는다.
- 1254px 투명 마스터를 보존하고 512px 셀 아틀라스를 128px로 표시한다. Unity 편의를 이유로 원화 품질을 낮추지 않는다.
- 현재 아트로 거짓 발효·오븐·완성 빵 프레임을 만들지 않는다. 느낌 검증판은 `한 덩이 반죽을 계속 치대는 고양이`만 보여준다.
- 작업표시줄 고양이 옆에는 진행·단계·계속 작업 티켓을 상시 표시하지 않는다. 실제 플레이 기능과 연결되지 않은 정보 UI로 캐릭터 실루엣과 화면 공간을 소비하지 않는다.
- 무입력 기본 상태는 awake idle이며 v4 반죽을 자동 재생하지 않는다. 키는 익명 800ms 창의 수량만으로 일반/fast/overdrive를 선택하고 work를 마지막 키 이후 1.2초까지만 유지한다. 클릭·휠은 attention만 재생하며 work를 시작하지 않는다.
- awake idle 시간표는 alert 0~45초, curious 45~180초, sleepy 180~300초, doze 300초 이후다. 킁킁 one-shot은 curious에서만 18/26/22초 간격으로 한 번씩 예약하며 큐·중첩하지 않는다.
- 고양이 클릭은 작업표시줄 보상을 수령하지 않고 관리창 열기/닫기만 수행한다. 관리창 내부 생산 완료는 별도 시스템으로 유지한다.
- 몸/무대 안정성을 캐릭터 전체 정지로 해석하지 않는다. 작업표시줄 접촉 루트와 작업대는 고정하되 중요한 앞발 동작은 시선·고개, 어깨/전완, 반죽 접촉과 복귀가 연결돼야 한다.
- 같은 네 포즈의 시간·랜덤 간격·FX만 바꾸는 방식과 전신 CSS 흔들기는 모두 생명감 해결 경로에서 제외한다.
- 귀는 좌우를 따로 분리하고 기저부를 머리에 겹쳐 숨긴다. 귀 파닥은 시선·주의·접촉에 반응하는 짧은 동작 또는 드문 단발 idle이며, 양쪽이 매번 동시에 반복되지 않는다.
- 모자 밴드는 머리에 완전히 고정하고, 모자 윗부분 크라운/주름만 머리 움직임보다 약간 늦게 따라왔다가 정착한다. 모자 전체가 머리에서 미끄러지거나 독립적으로 둥둥 뜨면 실패다.
- 귀·모자·고개·앞발 FX를 매 동작마다 모두 겹치지 않는다. 주동작 하나와 보조동작 하나만 읽히도록 우선순위를 둔다.
