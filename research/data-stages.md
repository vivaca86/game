# Stage Data

Status: `source conflict / stage taxonomy reconciliation / Dexerto unlock-table crawl / official wiki value extract / current implementation gap-mapped`

Dexerto lists 13 stage unlock entries. The generated Dexerto crawl confirms a single 13-row table with no `Mad Forest` or `Milk Factory` item rows, though both appear as prerequisite text. GAMES.GG claims the world map has 15 stages and explicitly says Mad Forest is available at start. Steam achievement metadata separately exposes `Unlock Milk Factory`. The official release FAQ crawl adds a separate structure claim: 6 biomes, each with a few dungeons, and several floors inside each dungeon. The official wiki API crawl now exposes 9 dungeon pages after excluding the index/Village, with 16 named dungeon or difficulty variants when infobox `name` fields are expanded. `research/stage-taxonomy-reconciliation.md` now preserves this as a source-level split: 13 unlock-table rows, 14 Steam progression rows, 15 non-tutorial playable-stage candidates, 9 official-wiki dungeon pages, and 16 official-wiki expanded variants including `Tutorial`. The likely resolution is that `biome`, `dungeon/stage`, `difficulty variant`, `tutorial/onboarding`, and `unlock entry` are different layers, but this must be verified from the stage-select UI.
