# HTML5 Game Harness (Phaser + TypeScript + Vite)

## Requirements
- Node.js 20+
- npm 10+

## Setup
```bash
npm install
```

## Run (Dev)
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Validation
```bash
npm run typecheck
npm run lint
```

## Project Structure
- `src/core`: core state/config
- `src/data`: static data and constants
- `src/ui`: Phaser scenes and view logic
- `src/systems`: app/game bootstrap systems
