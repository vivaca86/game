# Combat Stage Components v002

Date: 2026-06-01

Purpose: second source pass for the Combat UI rebuild. This is not final approved production art.

## Changes From v001

- Adds side paper wings and hanging pins so the scene reads more like a theater object.
- Shrinks the player state panel and splits HP, energy, and block into readable stat tags.
- Widens the route strip and adds a visible connector line between room nodes.
- Adds a central combat-flow lane so the player standee, cards, and enemy intent feel connected.
- Preserves the five-card hand and End Turn click zones used by smoke tests.

## Current Status

This is a candidate source sheet for the runtime Combat v2 layout. It improves traceability and visual direction, but it does not complete the UI skin gate without screenshot scoring, full primary-screen coverage, final art approval, and automated verification.
