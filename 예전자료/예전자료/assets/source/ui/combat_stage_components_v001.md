# Combat Stage Components v001

Date: 2026-06-01

Purpose: source evidence for the Combat UI rebuild. This is not final approved production art.

## Intent

- Keep the combat playfield readable while sharing the Reward/Event popup-book material language.
- Preserve the lower hand area and right enemy intent area used by smoke tests.
- Remove the previous top-stack overlap where the player panel and route strip covered the title ribbon.

## Components

- `combat-stage-frame`: large paper theater frame with stitched arch and soft spotlight ellipses.
- `combat-title-ribbon`: stage title ribbon, kept clear of status panels.
- `compact-player-panel`: smaller player state block moved into the left playfield side.
- `compact-route-strip`: short route strip below the title ribbon.
- `playfield-safe-zone`: reserved readable combat action band and hand shelf guide.
- `enemy-intent-panel`: right-side enemy and intent cluster with the end-turn command.
- `hand-shelf`: five-card hand layout guide matching runtime click coordinates.

## Current Status

This source sheet is a layout and material-direction record for the runtime rebuild. It is candidate evidence only. Final UI completion still requires the rubric score, debug-less screenshot review, full-screen coverage, and automated verification.
