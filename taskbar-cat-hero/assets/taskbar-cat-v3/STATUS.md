# REJECTED EXPERIMENT — pot-bongo v3

상태: **사용자 콘셉트 검수 탈락 / 런타임 미연결**

이 폴더는 v2의 도구 공중부양과 손 관통을 구조적으로 없애기 위해 모든 도구를 제거하고 고양이가 냄비 테두리를 두드리게 한 실험이다.

## 유지 이유

- 실패를 숨기거나 같은 아이디어를 다시 생성하지 않기 위한 감사 증거.
- 크로마 원본과 알파 중간 결과를 통해 어떤 경로가 시도됐는지 확인 가능.

## 재사용 금지 이유

- 요리사 고양이가 냄비를 봉고처럼 두드리는 행동이 복장·직업·소품과 자연스럽게 연결되지 않는다.
- 기하학적으로 안전한 결과가 곧 좋은 게임 아이디어라는 잘못된 결론을 반복할 수 있다.

이 폴더의 이미지는 런타임, IP 홀더 전달용 최종 시안, 반죽 콘셉트의 기준 원화로 사용하지 않는다. 다음 방향은 `../../docs/recovery-audit.md`와 `../../docs/current-issues-and-plan.md`를 따른다.
